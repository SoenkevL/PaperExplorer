- 2026-10-24 — GROBID's Citation Link is no evidence when the entry's first author is none of the surnames the marker prints: a wrong link is worse than an Unlinked Citation. An entry printed without a year (the Seed's Carhart-Harris OSF preprint) stays unmatched for now

- 2026-10-28 — Langfuse Python SDK v5 on its own tracer provider (never the global one); scripts use only v4's APIs, since Langfuse Cloud drops the v3 endpoints on 2026-11-16
- 2026-10-28 — Footnotes are chunked like paragraphs: they are the authors' words and the reader shows them. Headings are not Chunks; they give the Heading Path. A page footer GROBID files as a note becomes a `short` Chunk
- 2026-10-28 — Chunks split at GROBID's sentence spans; pysbd is not needed: a scan falls back to the end-punctuation rule its Citing Sentences already use (`parsing.sentence_spans`). Where GROBID's spans overlap (accents set apart from their letters), a sentence starts where the one before it ends
- 2026-10-28 — The bge-m3 tokenizer (`tokenizer.json`, MIT, pinned revision) ships xz-compressed inside `chunking` (2.4 MB), so tests, the Mac and the containers count tokens offline with no download step
- 2026-10-28 — `tokenizers` stays below 0.23: its huggingface-hub 2 brings httpx2, which turns Starlette's TestClient into an httpx2 client that the API's typed client (httpx) does not accept
- 2026-10-28 — A Chunk's span and sentences are code-point offsets into its block's text, so a Pointer's place is a Chunk sentence as stored. Its page and boxes are the block's: parse keeps no boxes per sentence
- 2026-10-28 — `short` marks every Chunk under 30 tokens, including a piece beside an oversized sentence; windows are balanced by the smallest sum of squared sizes; `chunk(doc)` stays pure, so a Chunk's Work comes with `StoredChunk`
- 2026-10-28 — Chunk embeddings get their own table, one Vector per Chunk with its model's name, deleted with the Chunk through `(work_id, chunk_id)`; `vector(1024)` (bge-m3) under an HNSW cosine index. A model with other dimensions needs a migration
- 2026-10-28 — The `embed` Stage embeds only the Chunks without a Vector from the Embedder's model: a second run embeds none, a new model re-embeds all. As the chain is ordered, it makes `extract_citations` pending
- 2026-10-28 — Batching lives in the OpenAI-compatible adapter (`PE_EMBEDDING_BATCH_SIZE`, 32), so a Question's one text and a Stage's Chunks take the same path; each request is one `embeddings <model>` observation under the current trace, and outside a trace nothing is recorded. `StageContext` carries `Tracing`
- 2026-10-28 — Vectors cross psycopg as `float8[]` cast to `vector` and come back as `real[]`: no pgvector Python package, no numpy
- 2026-10-28 — `FakeEmbedder` sets one blake2b-hashed dimension per distinct content word (case-folded, a short stop-word list left out): the cosine of two texts is their shared words over the root of the product of their word counts, so later stages' tests can reason about it
- 2026-10-28 — Scope is a set of Works in `domain`, for now built for one Work alone (`Scope.of`); Explorations will widen it. The searches of a model answering a Question take a Scope too, but are not Retrieval Runs
- 2026-10-28 — The full-text half matches any English stem of the query, not all: `plainto_tsquery` with its ANDs turned into ORs, ranked by `ts_rank`. A natural-language Question rarely has all its words in one Chunk; `websearch_to_tsquery` and `plainto_tsquery` alone AND them
- 2026-10-28 — Each ranking goes `max(k, 50)` deep before RRF, so a search for fewer Chunks gives the first Chunks of a search for more; 50 is about half the Seed's 105 Chunks. Ties go in reading order
- 2026-10-28 — Retrieval sets `hnsw.iterative_scan = relaxed_order` and re-ranks the Vectors strictly: once many Works hold Vectors, a filtered HNSW scan would otherwise stop at `ef_search` (40) candidates and could return none of the Scope's Chunks. No index on `work_id` yet; one Work's Vectors are scanned in full
- 2026-10-28 — The hybrid SQL lives in `Chunks.search` (SQL stays in `store`); `retrieval.search` embeds the text, picks the depth and skips an empty text without embedding it. A result is a `StoredChunk` with both rankings' rank and score, either empty when that ranking missed it, and its RRF
- 2026-10-28 — The resolved Answer's text is the draft without its handles (and the spaces before them; a handle starting its line takes the whitespace after it), so every offset of the Answer counts into the text the reader sees
- 2026-10-28 — Handles are `[#n]`; `[#n, #m]` is read as `[#n][#m]`. A handle belongs to the sentence it stands in or whose full stop it follows; a handle the Conversation does not know is dropped and counted (`unknown_handles`)
- 2026-10-28 — An Answer's sentences end at `.`, `!` or `?` before whitespace and a capital, and at every line break (list items, paragraphs)
- 2026-10-28 — A sentence with several handles gets one Pointer per cited Chunk, each resolved on its own in the order written; Pointers that reach the same place (overlapping Chunks share a sentence) are one
- 2026-10-28 — A Pointer also carries its Chunk's id and span, for the faint highlight of the rest of the Chunk, and the cosine it was judged by, for the eval to set the threshold from
- 2026-10-28 — Support threshold `PE_SUPPORT_THRESHOLD` = 0.7 (bge-m3 cosine) until the eval sets it: a paraphrase sits well above, another sentence on the same topic below; erring high marks Support weak rather than calling it close
- 2026-10-28 — Only double quotation marks, straight or curly, closed on their line, make a Quote; single marks stay prose, since the closing one is also the apostrophe. A Quote can therefore not mark words in single quotes as the authors'; it never marks them wrongly
- 2026-10-28 — The fixtures' block text holds no ligature code points (pdfium spells them out), and every line-break hyphen arrives as a soft hyphen that parsing joins, compounds too (`cause-|effect` → `causeeffect`, `bell-|shaped`, `drug-|related` among the 465 in three fixtures). So Quote matching drops a hyphen between letters, with any whitespace after it (an unmarked line-end hyphen reads `self- organizing`), on both sides; ligatures are spelled out and whitespace runs are one space, for matching only
- 2026-10-28 — Quotes match at word boundaries only, case and apostrophes as printed (a straight apostrophe against a printed curly one is not exact; the eval will show whether that needs folding). Punctuation the model put inside the closing mark stays outside an exact Quote when the authors' text goes on without it
- 2026-10-28 — A Quote found in several Chunks read this turn links to the one its sentence points at, else to the first in the order read
- 2026-10-28 — Pointer coverage counts substantive sentences only: not a question, not ending in a colon, at least four words
- 2026-10-28 — pydantic-ai-slim 2.x (and openai 3.x, genai-prices) require httpx2, which turns Starlette's TestClient into an httpx2 client; rather than pin a year-old pydantic-ai, the API's `ApiClient` takes any client with a fitting `get` (a Protocol), so httpx and httpx2 clients both fit. The `tokenizers<0.23` pin no longer keeps httpx2 out
- 2026-10-28 — The Seed's map shows the Chunks before its first heading as its abstract (GROBID's abstract arrives as paragraphs without a Heading Path), up to 1,500 tokens, with their handles; they count as read every turn. Sections get § numbers, apart from the Chunks' `[#n]`, and `read_section` takes a § number or a heading
- 2026-10-28 — At the request limit, the sixth request offers no tools and says it is the last, so the model answers from what it read; a model that still calls a tool ends the turn with an error and the Conversation stays as before
- 2026-10-28 — The model's thinking is traced on its request's span and left out of the deltas, the Answer and the Conversation's kept messages, so earlier turns' reasoning does not fill the context
- 2026-10-28 — The system prompt's version is its file's SHA-256 (12 hex digits): an edit cannot forget to change it
- 2026-10-28 — `Conversation` lives in `asking`, since it holds pydantic-ai's messages; `ask(ctx, conversation, question)` takes an `AskingContext` as `run_stage` takes a `StageContext`, and runs the turn in its own task so the trace's context stays inside it; closing the stream cancels the turn
- 2026-10-28 — The tools call the store and the Embedder in the event loop, blocking it for their few milliseconds: one connection, and the Chunks read in a fixed order. The API can move a turn to a worker thread if that ever matters
- 2026-10-28 — The chat model uses pydantic-ai's Ollama provider profile (thinking from `reasoning`, no `strict` tool schemas) at `PE_CHAT_BASE_URL`; `PE_CHAT_NUM_CTX` repeats the Modelfile's `num_ctx` for the traces
- 2026-10-28 — `reference(handle, marker)` matches the marker as printed or the label of the Reference a Citation links to, so `[4]` finds the Citation a printed range `[3–5]` stands for; `citing_sentences` shows each Citing Sentence under its Chunk's handle, and those Chunks count as read
